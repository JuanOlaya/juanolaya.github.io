# MemoDeutsch — funciones actuales para el prototipo

Este inventario describe lo que aparece actualmente en el menú principal del proyecto. El prototipo inicial debe representarlo tal como está, sin incorporar mejoras ni asumir funciones que no aparecen en la aplicación.

## Inicio

- Página principal titulada MemoDeutsch.
- Acceso al cambio de tema claro/oscuro.
- Navegación por tarjetas a los módulos de aprendizaje.
- Acceso a la versión anterior.

## Módulos del menú

| Módulo | Opciones actuales visibles |
|---|---|
| **Verbos** | Niveles A1, A2, B1 y B2, cada uno con su descripción temática. |
| **Sustantivos** | Curso principal, partes del cuerpo, tiempo y calendario, ropa, prueba LiD, LiD compacto y adjetivos LiD. Se describe como vocabulario y género. |
| **Adverbios** | Adverbios general, preparación DTZ B1 y expresiones adverbiales. |
| **Conectores** | Preposiciones, expresiones de cantidad, conjunciones general, conjunciones DTZ B1 y contracciones. |
| **Casos** | Nominativo, acusativo, dativo y pronombres reflexivos. |
| **Patrones de frases** | Acceso a estructuras útiles para hablar. |
| **Preguntas W** | Preguntas con wer, wie, was y wo. |
| **La hora** | Expresiones para indicar la hora. |
| **Adjetivos** | Deklination y colores. |
| **Expresión oral** | Pronunciación, interjecciones, práctica oral A1 y dos versiones de presentación de Angela para B1 (una con voz real y otra anterior). |
| **Escritura** | Expresiones administrativas y escritura A1. |
| **Versión anterior** | Enlace a la interfaz clásica. |

## Identidad visual documentada

- Colores de nivel: A1 azul y verde; A2 azul y naranja; B1 morado; B2 rosa/rojo.
- Modos oscuro y claro definidos para la vista compacta.
- Tipografías de marca documentadas: Nunito, Poppins y Kalam/Patrick Hand.
- El diseño de verbos contempla grupos temáticos de hasta siete verbos, etiquetas de nivel y tarjetas de detalle con traducción y pestañas de conjugación.

## Alcance visual inicial

Representar en Penpot el menú actual y las pantallas representativas de los flujos existentes. Este documento es un inventario de referencia; no redefine el producto ni propone cambios funcionales.

## Fuentes del proyecto

- `index.html`: menú principal, opciones y enlaces actuales.
- `DESIGN.md`: colores, tipografías y reglas visuales documentadas.
- `CLAUDE.md`: convenciones específicas del contenido de verbos.
