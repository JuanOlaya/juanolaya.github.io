Sockets — proyecto archivado

Este era un ejemplo de tutorial de p5.js con Node, Express y socket.io. Necesita un servidor Node en ejecución, algo que GitHub Pages no puede ofrecer, así que aquí nunca llegó a conectarse.

El código se conserva en server/sockets/ del repositorio. Para probarlo en local: cd server/sockets && npm ci && npm start y abre http://localhost:3000.
